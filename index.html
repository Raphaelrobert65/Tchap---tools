Tchap - Tools

Outil interne

Retrouver une instance, générer un MXID et vérifier l’ouverture d’un domaine. Cliquez sur une valeur pour la copier.

Fonctionnalité 1

Retrouver une instance

Renseigner un domaine professionnel. L’outil identifie automatiquement l’instance Tchap associée.

Fonctionnalité 2

Générer un MXID

Renseigner un email professionnel. L’outil construit automatiquement le MXID.

Fonctionnalité 3

Vérifier si un domaine est ouvert

Renseigner un domaine. Vérifier le statut d’ouverture directement dans l’interface principale.
